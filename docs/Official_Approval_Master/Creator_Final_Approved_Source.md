## Design Framework

- Creator psychological core: 「自分の内側にあるアイデアや想いを形にし、新しい価値や表現として生み出す力」
- Measurement order: Emotion → Internal Psychology → Decision → Behavior

### Measurement Classification

| Stage | Classification |
|---|---|
| Emotion | アイデア、表現、挑戦に対して心が動く初発感情 |
| Internal Psychology | 自分らしい価値や届けたい思いを捉え直す内的姿勢 |
| Decision | 工夫、改善、表現方法から形にする方向を選ぶ判断 |
| Behavior | 試作、伝達、改善、発表によってアイデアを形にする行動 |

### Design Rationale

課題、学習、対話、挑戦、制作、発表などの場面を通じて、内側の思いから新しい価値や表現を生み出す創造力を測定する。回答本文はEvidenceに固定し、分析分類は回答本文と分離して記録する。
