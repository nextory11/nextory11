## Design Framework

- Guardian psychological core: 「大切な人や価値あるものを守り、責任を持って安心できる状態を維持しようとする力」
- Measurement order: Emotion → Internal Psychology → Decision → Behavior
- Boundary from Harmony: 関係性の調整ではなく、守るべきものの維持と責任遂行を測定する。
- Boundary from Empath: 感情理解そのものではなく、相手や状況を守るための判断と行動を測定する。

### Measurement Classification

| Stage | Classification |
|---|---|
| Emotion | 安心・懸念・責任感など、守る対象に対する初発感情 |
| Internal Psychology | 安全・秩序・約束・配慮を維持しようとする内的姿勢 |
| Decision | 守るべきものと現実条件を確認し、安定につながる選択を行う判断 |
| Behavior | 確認・準備・支援・是正によって安心できる状態を実現する行動 |

### Design Rationale

日常の準備、約束、秩序、安全、問題対応、他者支援の場面を通じて、初発感情から内的心理、判断、行動へ至る守護力の現れを測定する。回答本文はEvidenceに固定し、分析分類は回答本文と分離して記録する。
