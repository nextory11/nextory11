## Design Framework

- Explorer psychological core: 「未知や新しい可能性に対して興味を持ち、自分自身で探索しながら理解を深めていく力」
- Measurement order: Emotion → Internal Psychology → Decision → Behavior
- Intuitive boundary: 感覚的に可能性を感じ取ることではなく、実際に探し、試し、理解を深める力を測定する。
- Pioneer boundary: 道を切り開くことではなく、未知を知り、経験し、理解する力を測定する。
- Creator boundary: 新しいものを生み出すことではなく、世界から情報や経験を取り入れる力を測定する。

### Measurement Classification

| Stage | Classification |
|---|---|
| Emotion | 未知や新しい経験に対する興味・驚き・高揚などの初発感情 |
| Internal Psychology | 答えや背景を自分で知り、理解を広げようとする内的姿勢 |
| Decision | 未知へ近づく方法や、試す対象を選択する判断 |
| Behavior | 調べる・訪れる・試す・尋ねることで理解を深める行動 |

### Design Rationale

旅行、街歩き、学習、食事、創作、贈り物などの日常場面を通じて、未知への初発反応から探索行動までを測定する。回答本文はEvidenceに固定し、分析分類は回答本文と分離して記録する。
