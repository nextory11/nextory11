# NEXTORY11 Official Approval Master

## Authority

This directory is the permanent authoritative documentation source for officially approved NEXTORY11 Question Design content.

The authority flow is one-way:

HIRO Review

↓

Official Approval Master

↓

Review Master

↓

Question Bank Candidate

↓

Production

Never reverse this flow.

Review Master, browser storage, Question Bank JSON, candidate files, runtime data, and Production are downstream representations and must never become the authoritative wording source.

## Version 3.5 Package

The package contains 11 type files and 220 Question ID records.

A record is complete only when all of the following are present from a traceable approved source:

- Final Approved Question
- Final Approved Answers A–D
- HIRO Approved status
- JUZA Final status
- READY status
- Question Design Version 3.5
- Source Reference
- Approval Metadata

A declared approval state does not make a record transferable when its exact approved wording or traceable source reference is missing.

## Source Rule

Question ID is the only authoritative matching key.

Do not match by array position, Question Bank order, browser order, chat memory, or inferred type sequence.

Approved wording must never be rewritten, normalized, corrected, reconstructed, or copied from the existing Question Bank as a substitute source.

## Placeholder Rule

`BLOCKED — traceable approved wording not supplied.` means the record structure exists but the authoritative content transfer is incomplete.

Blocked records must not be synchronized to Review Master, Question Bank Candidate, or Production.
