## Design Framework

- Evolver psychological core: 「過去の経験から学び、変化を受け入れながら、自分自身を成長させ続ける力」
- Measurement order: Emotion → Internal Psychology → Decision → Behavior
- Intuitive boundary: 形にならない可能性の感知ではなく、経験を通じた自己変化と成長を測定する。
- Explorer boundary: 未知の探索ではなく、経験を自分の変化や成長につなげる力を測定する。
- Pioneer boundary: 新しい道の開拓ではなく、経験から学び自分を進化させる力を測定する。

### Measurement Classification

| Stage | Classification |
|---|---|
| Emotion | 変化、失敗、過去との再会に対する初発感情 |
| Internal Psychology | 経験の意味を捉え直し、自己変化を受け入れる内的姿勢 |
| Decision | 過去の経験を踏まえ、次に活かす方向を選ぶ判断 |
| Behavior | 振り返る、工夫する、再挑戦することで成長につなげる行動 |

### Design Rationale

日常の変化、失敗、思い出、再挑戦、他者の経験を通じて、経験の受容から自己更新へ至る成長力を測定する。回答本文はEvidenceに固定し、分析分類は回答本文と分離して記録する。
